# 智慧仓储管理系统（WMS）系统架构

> 文档版本：v1.0　|　更新日期：2026-08-30

---

## 1. 总体架构

系统采用 **前后端分离 + 单容器一体化部署** 的架构：开发期前后端独立运行（Vite Dev Server + Express），生产期由后端托管前端静态文件，打包进单个 Docker 镜像，实现"一条命令交付"。

```mermaid
flowchart TB
    subgraph Client["客户端（浏览器 / 手机 H5）"]
        UI["React 19 SPA<br/>Vite + Tailwind + Radix UI"]
    end

    subgraph Server["Node.js 20（单容器）"]
        Express["Express 4 应用"]
        Static["静态文件托管<br/>（生产环境托管前端 dist）"]
        Auth["认证中间件<br/>JWT + bcrypt"]
        Routers["业务路由<br/>auth/items/locations/inbound/outbound/<br/>inventory/billing/users/alerts/audit"]
        DB["better-sqlite3<br/>wms.db（WAL 模式）"]
    end

    subgraph Persist["数据持久化"]
        Volume["Docker 卷 /app/data<br/>→ 宿主机 ./wms-data"]
        Backup["每日备份脚本<br/>保留 30 天"]
    end

    UI -->|"/api/* 请求"| Express
    Express --> Static
    Express --> Auth
    Auth --> Routers
    Routers --> DB
    DB --> Volume
    Volume --> Backup
```

## 2. 前端架构

```mermaid
flowchart LR
    entry["main.tsx"] --> App["App.tsx<br/>QueryClient + Router + AuthProvider"]
    App --> Router["React Router 7"]
    App --> Query["TanStack Query 5"]
    App --> AuthCtx["AuthProvider（Context）"]

    Router --> Protected["ProtectedRoute<br/>（登录 / 管理员守卫）"]
    Protected --> Layout["AppLayout<br/>侧边栏 + 页面框架"]
    Layout --> Pages["pages/<br/>Dashboard/Inbound/Outbound/<br/>Inventory/Alerts/Fees/BillingRules/<br/>AdminItems/AdminLocations/AdminUsers/<br/>AuditLogs/Login"]

    Pages --> Components["components/<br/>ui（Radix + shadcn）/ layout / form"]
    Pages --> ApiClient["lib/api-client.ts<br/>axios 实例 + 拦截器"]

    Query --> ApiClient
    ApiClient -->|"Bearer Token"| Backend["后端 /api"]
```

**分层职责：**

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 页面层 | `src/pages/` | 路由页面，编排业务逻辑 |
| 组件层 | `src/components/` | UI 组件（ui / layout / form / 业务组件） |
| 状态层 | `src/hooks/` | `use-auth`（认证状态）、`use-mobile` |
| 数据层 | `src/lib/api-client.ts` | axios 实例、拦截器、错误处理 |
| 类型层 | `src/types/` | TypeScript 类型定义 |

## 4. 数据流（出库计费核心链路）

```mermaid
sequenceDiagram
    participant U as 操作员
    participant F as 前端 Outbound 页
    participant B as 后端 /outbound/create
    participant DB as SQLite

    U->>F: 填写去向/日期/型号/数量
    F->>B: POST /api/outbound/create
    B->>DB: 查询该型号剩余库存
    DB-->>B: 库存不足? → 400 拦截
    B->>B: 开启事务 trx()
    B->>DB: 插入 outbound_records（占位）
    B->>DB: 按 inbound_date ASC 查询可出库批次
    loop 每个批次（FIFO）
        B->>B: matchRule(item_id, location_id, date)
        B->>B: days = max(出库-入库天数, min_days)
        B->>B: fee = take × days × price_per_day
        B->>DB: 扣减 remaining_qty
    end
    B->>DB: 写入 outbound_batches + fee_details
    B->>DB: 更新 total_fee / storage_fee / manual_fee
    B-->>F: 返回出库记录与费用
    F-->>U: 展示批次与费用明细
```

## 5. 部署架构

```mermaid
flowchart TB
    subgraph SingleTenant["单客户单机部署（一条命令）"]
        D1["docker compose up -d"]
        D1 --> C1["容器 wms<br/>（后端 + 前端静态文件）"]
        C1 --> V1["宿主机 ./wms-data/wms.db"]
    end

    subgraph MultiTenant["服务商多租户部署"]
        S["/opt/wms/deploy/new-tenant.sh acme"]
        S --> C2["容器 wms-acme :8001"]
        S --> C3["容器 wms-baker :8081"]
        C2 --> V2["/data/wms/acme/wms.db"]
        C3 --> V3["/data/wms/baker/wms.db"]
        Nginx["nginx 域名反代（可选 HTTPS）"]
        Nginx --> C2
        Nginx --> C3
    end

    subgraph Ops["运维"]
        Backup["backup.sh<br/>crontab 每日备份"]
        Package["export-package.sh<br/>打包交付 tar.gz"]
        Backup --> V2
        Backup --> V3
    end
```

**关键点：** 每个客户 = 独立容器 + 独立数据库文件 + 独立随机 JWT 密钥，物理隔离、零数据交叉。
