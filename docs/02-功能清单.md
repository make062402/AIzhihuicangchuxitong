## 二、功能明细

### 1. 登录认证

| 功能点 | 说明 | 状态 |
| --- | --- | --- |
| 账号密码登录 | 用户名/邮箱/手机号 + 密码 | ✅ |
| 邮箱验证码登录 | 发送 6 位验证码到邮箱 | ✅（模拟发送） |
| 手机短信登录 | 发送验证码到手机 | ✅（模拟发送） |
| JWT 会话保持 | token 存 localStorage，请求自动附带 | ✅ |
| 路由守卫 | 未登录跳转 `/login`，管理员路由二次校验 | ✅ |

### 2. 库存总览（Dashboard）

| 功能点 | 说明 |
| --- | --- |
| 库存总量 / SKU 数 / 库位占用率 | 实时统计卡片 |
| 今日出入库统计 | 当日入库、出库数量 |
| 出入库趋势曲线 | 近 14 天趋势（Recharts 折线图） |
| 月度费用总览 | 当月累计计费金额 |
| 库位热力图 / TOP 型号 | 可视化辅助决策 |

### 3. 入库管理（Inbound）

| 功能点 | 说明 |
| --- | --- |
| 入库登记 | 来源、入库日期、物品型号、数量、存放位置 |
| 库存台账更新 | 自动写入批次，记录剩余可出库数 |
| Excel 批量导入 | 使用 xlsx 解析上传文件 |
| 模板下载 | 提供标准导入模板 |
| 列表检索 | 关键字 + 日期区间过滤 |

### 4. 出库管理（Outbound）

| 功能点 | 说明 |
| --- | --- |
| 出库登记 | 去向、出库日期、物品型号、数量 |
| 型号动态关联 | 下拉仅显示有库存的型号 |
| FIFO 批次分配 | 按入库时间先后自动拆分批次 |
| 存放天数计算 | 入库日期 → 出库日期的天数（最小 1 天） |
| 自动计费 | 逐批匹配计费规则，计算存储费 |
| 人工/附加费 | 支持录入 labor / extra 类型费用 |
| 库存校验 | 库存不足时拦截并提示可出库数量 |
| 详情查看 | 出库记录、批次明细、费用明细 |

### 5. 计费规则引擎（Billing Rules）

| 功能点 | 说明 |
| --- | --- |
| 多维匹配 | 物品型号 + 库位 + 日期区间 |
| 计费方式 | 日租金、最低起租天数（min_days） |
| 四级匹配层级 | L1 物品+库位 > L2 物品 > L3 库位 > L4 通用 |
| 规则启停 | active 开关 |
| 权限控制 | 仅管理员可维护 |

### 6. 库存明细（Inventory）

| 功能点 | 说明 |
| --- | --- |
| 库存查询 | 按物品/库位查看剩余数量 |
| 批次追溯 | 查看各入库批次及剩余量 |

### 7. 库存预警（Alerts）

| 功能点 | 说明 |
| --- | --- |
| 断货预警（out_of_stock） | 库存为 0 |
| 库存偏低（low） | 低于 low_threshold |
| 库存过高（high） | 高于 high_threshold |
| 滞留过久（aging） | 存在超过 aging_days 未出库批次 |
| 阈值设置 | 管理员为物品设置低/高阈值、老化天数 |

### 8. 费用明细（Fees）

| 功能点 | 说明 |
| --- | --- |
| 费用构成追踪 | storage（存储）/ labor（人工）/ extra（附加） |
| 批次小计 | 每笔费用对应出库批次 |
| Excel 导出 | 费用清单导出 |

### 9. 系统管理（Admin）

| 功能点 | 说明 |
| --- | --- |
| 用户管理 | 增删改、重置密码、切换角色（admin/operator） |
| 物品型号管理 | SKU 型号、名称、单位、分类 CRUD |
| 库位管理 | 库位编号、区域、容量 CRUD |
| 操作日志 | 按用户/资源/动作/时间检索，含统计 |

## 三、API 端点清单

> 统一前缀 `/api`，请求均为 POST（JSON body）。

| 模块 | 端点 | 权限 |
| --- | --- | --- |
| 系统 | `GET /api/health`、`/health/ready`、`/health/live` | 公开 |
| 认证 | `/auth/login` | 公开 |
| 认证 | `/auth/send-email-code`、`/auth/send-sms-code`、`/auth/verify-code` | 公开 |
| 认证 | `/auth/me` | 登录 |
| 物品 | `/items/list`、`/items/create`、`/items/update`、`/items/delete` | 登录（写操作管理员） |
| 库位 | `/locations/*` | 同上 |
| 入库 | `/inbound/list`、`/inbound/create`、`/inbound/import` | 登录 |
| 出库 | `/outbound/list`、`/outbound/create`、`/outbound/detail` | 登录 |
| 库存 | `/inventory/summary`、`/inventory/list` | 登录 |
| 计费 | `/billing/rules/*` | 管理员 |
| 计费 | `/billing/fees/*` | 登录 |
| 用户 | `/users/*` | 管理员 |
| 预警 | `/alerts/summary`、`/alerts/thresholds/*` | 登录（阈值写管理员） |
| 审计 | `/audit/list` | 管理员 |
