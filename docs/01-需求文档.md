# 智慧仓储管理系统（WMS）需求文档

> 文档版本：v1.0　|　更新日期：2026-08-30　|　状态：已实现

---

## 1. 文档目的

本文档定义「智慧仓储管理系统（Smart WMS）」的产品需求，作为开发、测试、验收与客户交付的统一依据。系统面向中小型仓储企业，覆盖**入库、出库、库存、自动计费**全流程，通过多维度计费规则和精确的存放时间追踪，帮助企业提升仓储运营效率。

---

## 2. 项目背景与目标

### 2.1 背景

中小型仓储企业（第三方仓储、电商仓、工厂原料仓等）普遍面临以下痛点：

- 出入库靠手工台账，账实不符、易出错；
- 计费规则复杂（按型号、库位、存放时长差异化计价），人工算费慢且易漏；
- 缺少库存预警，常出现断货、积压、货物滞留老化；
- 多客户服务商需要为每个客户做数据隔离，但又不愿承担高昂的分布式部署成本。

### 2.2 目标

1. 提供**一体化**出入库 + 库存 + 计费管理平台；
2. 实现**自动计费**：出库时按 FIFO 批次自动计算存放天数和费用；
3. 提供**库存预警**看板，及时识别异常；
4. 支持**一客户一部署**的轻量私有化交付，降低部署门槛；
5. 具备**审计留痕**与**分级权限**，满足基本合规要求。

### 2.3 非目标（本期不做）

- 多仓库 / 多组织集团化协同；
- 与外部 ERP / 财务系统的自动对接（仅支持 Excel 导入导出）；
- 移动端原生 App（以 H5 自适应替代）。

## 3. 目标用户与角色

| 角色 | 说明 | 权限范围 |
| --- | --- | --- |
| **管理员（admin）** | 企业负责人 / 仓储主管 | 全部功能 + 用户管理 + 计费规则 + 物品/库位管理 + 操作日志 |
| **操作员（operator）** | 一线仓管员 | 出入库操作 + 库存/费用/预警查看 |

> 系统内置两个角色，权限在后端中间件层强制校验（`adminRequired`），前端仅做界面隐藏。

## 5. 非功能需求（NFR）

| 编号 | 类别 | 需求描述 |
| --- | --- | --- |
| NFR-01 | 性能 | 常规列表查询响应 < 500ms；单客户数据量 10 万级记录下运行流畅 |

| NFR-06 | 可交付性 | 单容器一条命令启动，客户无需技术背景即可部署 |
| NFR-07 | 可观测性 | 结构化日志（pino），提供健康检查端点 |

## 6. 验收标准（摘要）

1. 管理员可完成一次完整业务闭环：录物品 → 建库位 → 定计费规则 → 入库 → 出库 → 查看费用与预警；
2. 出库时费用按 FIFO 批次自动计算，与手工核算一致；
3. 库存不足时系统拦截并给出明确提示；
4. 操作员无法访问管理员专属接口（后端 403）；
5. 交付包解压后 `docker compose up -d` 可正常启动并访问。
